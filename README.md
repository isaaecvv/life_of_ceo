# Life of CEO

Личный трекер дня для iPhone: расписание, задачи, вода, сахар, питание с БЖУ, сон, траты, рефлексия и ассистент.

- `web/ui.html` — интерфейс приложения (правки делаются здесь, затем `npm run build:web`).
- `App.tsx` — нативная часть: хранение данных, системные уведомления, голос, вибрация, резервная копия.
- `.github/workflows/build-ios.yml` — сборка `LifeOfCEO.ipa` без подписи для установки через SideStore.

Готовый файл появляется в разделе **Releases** после каждой сборки.
